DATABASE SCHEMA REQUIRED
================================================================================

Three tables must exist in Supabase:

1. transactions
   id (UUID), user_id (UUID), amount (DECIMAL), category (TEXT),
   date (DATE), type (TEXT), description (TEXT), created_at (TIMESTAMP)

2. budgets
   id (UUID), user_id (UUID), category (TEXT), limit_amount (DECIMAL),
   period (TEXT), created_at (TIMESTAMP)

3. goals
   id (UUID), user_id (UUID), name (TEXT), target_amount (DECIMAL),
   deadline (DATE), category (TEXT), created_at (TIMESTAMP)

See QUICK_START.md for SQL commands.
